# CodeAlpha Ecommerce Store - Updated LumiStore Dashboard

A Flask + SQLite e-commerce web application with a modern mobile-first LumiStore-style shopping dashboard.

## Features

- Product listing dashboard
- Search products
- Product details
- Add to cart
- Update/remove cart items
- User registration and login
- Checkout and order processing
- Order history
- SQLite database
- Responsive mobile-first interface
- Modern purple e-commerce UI

## Run

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start application:

```bash
python app.py
```

Open:

http://127.0.0.1:5000

Demo account can be created from the Register page.

## New Ecommerce Features
- Persistent wishlist for logged-in users
- Wishlist page and heart buttons on product cards
- Flipkart-inspired checkout flow with UPI, Card, Net Banking and Cash on Delivery demo options
- Delivery address collection
- Payment method stored with each order
- Updated 5-item mobile bottom navigation
